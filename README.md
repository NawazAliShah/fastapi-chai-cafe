# ☕ FastAPI Chai Cafe

A simple RESTful API built with FastAPI to manage a collection of teas. Perfect for learning CRUD operations using Python and FastAPI.

---

## 🚀 Features

- View welcome message at root (`/`)
- View list of all teas (`GET /teas`)
- Add a new tea (`POST /teas`)
- Update an existing tea by ID (`PUT /teas/{tea_id}`)
- Delete a tea by ID (`DELETE /teas/{tea_id}`)

---

## 📦 Requirements

- Python 3.11+
- FastAPI
- Uvicorn

Install dependencies:

```bash
pip install fastapi uvicorn
